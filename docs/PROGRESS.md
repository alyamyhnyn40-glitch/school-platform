# سجل التقدم (PROGRESS.md)

## المرحلة 0: الأساس — ✅ مكتملة (v0.1.0)
**أُنجز**
- هيكل المشروع، Router بـ Middleware، DB (PDO + transactions متداخلة)، Session آمنة، CSRF، Validator، Lang، Logger، معالجة أخطاء (JSON/HTML).
- طبقة Repository تفرض `school_id` من الجلسة فقط (`Tenant`) وتمنع Mass Assignment وترمي استثناء عند غياب السياق.
- نموذج البيانات الكامل: 92 جدولًا في 8 migrations تعمل على قاعدة فارغة، و`database/schema.sql` مجمّع.
- معالج التثبيت `/install` (فحص المتطلبات، `.env`، migrations، بيانات أساسية، مشغّل المنصة، يقفل نفسه).
- الدخول: بريد/هاتف + كلمة مرور، OTP عبر SMS، استعادة كلمة المرور، تغيير إجباري، قفل بعد 5 محاولات، Rate Limiting.
- `SmsGateway` (مزود log + مزود HTTP عام قابل للضبط).
- RBAC: كتالوج صلاحيات دقيقة (45) و7 أدوار مدرسة افتراضية.
- واجهة RTL (Bootstrap 5.3 RTL محليًا، خط Cairo، أيقونات، Chart.js)، وضع ليلي، PWA (manifest + Service Worker + offline)، متجاوبة.
- اختبارات PHPUnit: 29 اختبارًا (عزل المدارس، المصادقة، OTP، القفل، الصلاحيات، CSRF).
- التحقق اليدوي بالمتصفح عند 360 و1440px: لا أخطاء JS ولا تجاوز أفقي.

**اكتُشف وأُصلح أثناء التنفيذ**
- `Env::load()` كان يطغى على القيم المضبوطة برمجيًا فنفّذت الاختبارات على قاعدة التطوير. أُصلح، وأُضيف رفض صريح لتشغيل الاختبارات على قاعدة لا ينتهي اسمها بـ `_test`.
- `DB::transaction` لم يدعم التداخل → أصبح يستخدم SAVEPOINT.

**متبقٍ من المرحلة 0 (لاحقًا ضمن مراحل أخرى)**
- فحص أمان رفع الملفات وتقديمها عبر Controller (يُنفذ مع أول ميزة رفع في المرحلة 2).
- سكربت النسخ الاحتياطي `bin/backup.php` (في المرحلة 1).

## المرحلة 1: لوحة مشغّل المنصة — ✅ مكتملة (v0.2.0)
**أُنجز**
- المدارس: قائمة بحث/فلترة/ترقيم عبر AJAX، إنشاء مدرسة في transaction واحد (المدرسة + 7 أدوار + نظام درجات مبدئي + وحدات + اشتراك + مدير بكلمة مؤقتة تظهر مرة واحدة وتُلزم بالتغيير)، تعديل بتسجيل الفرق في التدقيق، تفعيل/إيقاف/أرشفة (الإيقاف يمنع دخول كل مستخدمي المدرسة فورًا)، إعادة تعيين كلمة مرور المدير.
- خطط الاشتراك: حدود عدد الطلاب والتخزين والوحدات؛ تغيير الخطة يحدّث وحدات المدارس المشتركة. `SubscriptionService` جاهز لفرض الحدود في الوحدات القادمة (`studentLimitReached`, `moduleEnabled`, `storageLimitReached`).
- الدعم الفني: دخول بسبب إلزامي، شريط تنبيه ظاهر، تسجيل في `support_access_logs` و`audit_logs` (علامة via_support)، إنهاء الدعم.
- سجل تدقيق المنصة بفلاتر (مدرسة/نوع/تاريخ) وترقيم.
- `bin/backup.php` (نسخة قاعدة PHP خالص + uploads، احتفاظ 14 يومًا، جُرّبت استعادتها)، `bin/cron-notifications.php` (طابور SMS مع إعادة المحاولة).
- اختبارات: 42 اختبارًا ناجحًا (13 جديدة للمرحلة). اختبار متصفح E2E: إنشاء مدرسة ← دخول المدير بكلمة مؤقتة ← تغيير إجباري ← 403 على صفحات وAPI المنصة ← دعم فني ← تدقيق ← إيقاف ← منع الدخول. لا أخطاء JS.

## المرحلة 2: النواة الأساسية — 🔶 قيد التنفيذ (الشريحة 2أ مكتملة، v0.3.0)
### 2أ ✅ الهيكل الأكاديمي والأشخاص
- السنوات والفصول (سنة فعّالة واحدة، إغلاق = قراءة فقط، فصول داخل حدود السنة)، المراحل والصفوف (مع «يُرقّى إلى»)، المواد، الشعب (سعة/نوع/مربٍّ، يتوافق مع نوع المدرسة)، إسناد المعلمين، نسخ هيكل سنة.
- **الترفيع الجماعي** مع معاينة وقرارات فردية (ترفيع/إعادة/انسحاب، وتخريج لآخر صف) وعملية ذرّية.
- الطلاب: ملف كامل (حقول حساسة مشفّرة)، هوية ثابتة عبر المنصة، رقم قيد تلقائي، بحث/فلترة/ترقيم AJAX، دورة الحياة (انسحاب/انتقال/تخرج/عودة) مع سجل، الانضباط، تسجيل ونقل بين الشعب مع فحص السعة والجنس، حد الاشتراك.
- أولياء الأمور متعدد-لمتعدد مع أساسي/اطلاع/استلام/قيد حضانة، وإنشاء حساب OTP.
- الموظفون والمعلمون: ملفات، حسابات بدور وكلمة مؤقتة، نطاق المعلم (طلابه فقط).
- اختبارات: 75 ناجحًا (33 جديدًا). متصفح E2E: تدفق كامل من السنة حتى الترفيع، المعلم يُمنع (403) من الإدارة ويرى طلابه فقط، جوال 360 بلا تجاوز.
### 2ب-1 ✅ الحضور والدرجات والشهادات (v0.4.0)
- **الحضور:** تسجيل سريع (حاضر/غائب/متأخر/بعذر + ملاحظة، «الكل حاضر»)، يعمل **دون اتصال** (IndexedDB + Service Worker: الصفحة تفتح دون شبكة وتُحمَّل كشوف اليوم مسبقًا، والعمليات تُزامَن تلقائيًا عند عودة الاتصال بأمان ضد التكرار)، نطاق المعلم، قاعدة تعديل الأيام السابقة، تقرير ملخص ونسب وكثيرو الغياب ورسم اتجاه يومي وتصدير Excel، وإشعار SMS اختياري لولي الأمر.
- **الدرجات:** نظام قابل للتهيئة (عظمى/نجاح/طريقة المعدل/أنواع تقييم بأوزان/سلّم تقديرات/لكل مرحلة)، تقييمات لكل مادة وفصل، **جدول إدخال شبيه Excel** بحفظ تلقائي AJAX وتنقل بالأسهم ودعم دون اتصال، التحقق من المدى، **الاعتماد والإقفال** (اعتماد تقييم، قفل فصل، إعادة فتح بسبب مُسجَّل)، سجل تدقيق بالقيمة القديمة والجديدة.
- **النتائج والشهادات:** معدلات وتقديرات وترتيب ونتيجة لكل طالب، مقارنة الشعب، تصدير Excel، إصدار شهادات فصلية (snapshot ثابت) بتصميم رسمي A4 قابل للطباعة وحفظ PDF.
- **سجل التدقيق لمدير المدرسة** بفلاتر.
- اختبارات: 116 ناجحًا (41 جديدًا: حساب الدرجات، الحضور، الدرجات، الشهادات، Excel). متصفح E2E كامل بلا أخطاء، بما فيه قطع الشبكة والمزامنة.
### 2ب-2 ✅ الاستيراد والبوابة (v0.5.0)
- **الاستيراد الجماعي** للطلاب (مع ولي الأمر والتسجيل في الشعبة) والموظفين وأولياء الأمور من xlsx/csv: قوالب، قراءة ملفات Excel حقيقية، معاينة بأخطاء كل صف، تقرير أخطاء xlsx، اعتماد للصفوف السليمة فقط، حماية من الاعتماد المزدوج وحدود الاشتراك.
- **بوابة الطالب وولي الأمر** (جوال أولًا): حضور 30 يومًا وآخر الغياب، الدرجات المعتمدة لكل فصل مع تنبيه «مؤقتة»، الشهادات المُصدرة (غير المسوّدة)، وقراءة فقط وبنطاق الأبناء. دخول الطالب برقم القيد، وولي الأمر بـOTP.
- إنشاء/إعادة تعيين حساب الطالب من ملفه.
- اختبارات: 143 ناجحًا (27 جديدًا). متصفح E2E: رفع Excel ← معاينة ← اعتماد ← حساب طالب ← دخول الطالب ← OTP لولي الأمر ← 403 على صفحات الإدارة.
### 2ب-3 ✅ الأدوار والجدول والشهادة النهائية (v0.6.0)
- **الأدوار والمستخدمون:** أدوار مخصصة بصلاحيات دقيقة (رائد النشاط، مشرف المرحلة…)، إسناد الأدوار، تعطيل/تفعيل، إعادة تعيين كلمة المرور؛ منع تصعيد الصلاحيات وحماية آخر مدير؛ **سريان فوري** للتعديل على الجلسات المفتوحة.
- **الجدول الدراسي:** أيام وحصص وقاعات قابلة للتهيئة، إدخال بنقرة مع **كشف تعارض** المعلم والقاعة والشعبة، حد الحصص الأسبوعية، جدول المعلم وجدول الشعبة، طباعة، وبطاقة «حصصي اليوم» في لوحة المعلم.
- **الشهادة النهائية** (تجميع الفصول) مع عرض النتيجة النهائية وترتيب الشعبة وإصدار كامل/جزئي.
- إصلاح قديم: قوائم `onchange` المضمّنة كانت محجوبة بسياسة CSP (قائمة السنة في الشعب)؛ حلّت محلها آلية عامة.
- لوحة المدرسة تُظهر كل إحصاء حسب صلاحية المستخدم.
- اختبارات: 171 ناجحًا (28 جديدًا). متصفح E2E بلا أخطاء JS: جدول، تعارض، إعدادات، لوحة المعلم، أدوار، سحب صلاحية فوري، نتيجة نهائية.

## المرحلة 3: الرسوم الدراسية — ✅ مكتملة (v0.7.0)
- **هياكل الرسوم** بنود وأقساط (عدد/فاصل/أول استحقاق) لسنة وصف أو للكل بعملة محددة، **خصومات ومنح** (نسبة/مبلغ/استثنائي بسبب)، **تعيين** فردي وجماعي لشعبة/صف مع **خصم الإخوة** تلقائيًا.
- **العملات** (ريال/دولار/ريال سعودي): أسعار صرف يدوية، تثبيت السعر في الدفعة والفاتورة، دفع بعملة مختلفة مع معاينة التحويل وسعر يدوي موثَّق.
- **التحصيل:** نقدي/بنك/محافظ/صرافة (رقم مرجع لغير النقدي)، توزيع على الأقدم، منع التجاوز، **سندات مرقمة بلا فجوات** قابلة للطباعة A4، إلغاء بسبب مع بقاء السند «ملغى».
- **الفواتير:** رسمية مرقمة بسطور وخصم وضريبة وسعر مرجعي، حالتها تتبع الدفعات، وإلغاؤها محكوم.
- **الضريبة:** مفعّلة/معفاة بلا نسبة افتراضية، شاملة/غير شاملة، تُجمَّد عند التعيين.
- **المتأخرات** بالعملة مع أيام التأخر وتذكير SMS (مرة يوميًا ولمن يحق له الاطلاع) وExcel؛ **تقرير التحصيل** حسب العملة والطريقة والأمين + Excel؛ **كشف حساب** مطبوع؛ لوحة الرسوم.
- **بوابة ولي الأمر:** كشف الرسوم والأقساط وطباعة السندات (قراءة فقط)؛ وحدة الرسوم تتبع خطة الاشتراك (ModuleMiddleware) وتُخفى من القائمة عند عدم تفعيلها.
- اختبارات: 207 ناجحًا (36 جديدًا للمال: الهللات، الأقساط، العملات، الترقيم بلا فجوات، الإلغاء، العزل، الصلاحيات). متصفح E2E كامل بلا أخطاء.
- **لم يُنفَّذ:** دفع إلكتروني آلي عبر بوابات (D-46)، وربط مباشر بنظام محاسبي (يوجد تصدير Excel).

## المرحلة 4: التعليم الإلكتروني والتواصل — ✅ مكتملة (v0.8.0)
- **الدروس والمواد:** دروس نصية بنشر/مسودة، مواد ملفات (PDF/Office/صور/نص) وروابط وفيديو، تنزيل محمي بالصلاحية.
- **الواجبات:** موعد وتعليمات ودرجة، تسليم نص/ملف مع تعديل قبل التصحيح، تأخر مسموح/ممنوع، تصحيح وتغذية راجعة، إشعارات.
- **بنك الأسئلة والاختبارات:** 4 أنواع، اختبار بمدة وفتح/إغلاق ومحاولات وترتيب عشوائي، حل بمؤقت وحفظ تلقائي وتسليم آلي، تصحيح آلي للموضوعي ويدوي للمقالي، ضوابط نزاهة من جهة الخادم.
- **الحصص المباشرة:** Jitsi/Zoom/Meet/Teams/BBB بروابط، دخول بنافذة جديدة، حضور آلي في وحدة الحضور.
- **التواصل:** إعلانات (جمهور/شعبة، SMS اختياري)، رسائل داخلية مقيّدة بالعلاقات مع محادثات وعدّاد غير مقروء، جرس إشعارات.
- **واجهة الطالب** (موادي): جوال أولًا. وحدتا lms وcomms تتبعان خطة الاشتراك.
- اختبارات: 242 ناجحًا (35 جديدًا). متصفح E2E كامل بلا أخطاء: معلم ينشئ كل شيء ← طالب يحل ويسلّم ← تصحيح ← ولي أمر يراسل ← منع التسلل.
- **لم يُنفَّذ:** منتدى/تواصل بين الطلاب (SPEC §3.6)، مزود واتساب فعلي، نقل درجات الاختبار آليًا إلى سجل الدرجات.

## المرحلة 5: القبول والإنذار المبكر والرواتب والمرافق والإرشاد والشهادات والتحليلات — ✅ مكتملة (v0.9.0)
- **القبول والتسجيل:** طلبات التحاق بمسار حالات، رفع وثائق محمية، منع التكرار، وتسجيل الطالب في شعبة بنقرة (ينشئ الطالب وولي الأمر).
- **الإنذار المبكر:** 6 مؤشرات قابلة للضبط مع تفسير نصي لكل تنبيه، مراجعة/استبعاد بسبب/فتح حالة إرشاد، فحص يدوي وفحص يومي مجدول (`bin/cron-risk.php`). لا إشعارات تلقائية.
- **الإرشاد الطلابي:** حالات وملاحظات **مشفّرة**، اطلاع مُدقَّق.
- **الرواتب والعقود:** عقود بلا تداخل، كشف شهري (مسودة ← معتمد ← مصروف) بتناسب الأيام، بدلات/خصومات يدوية، قسيمة A4، تصدير Excel، إجماليات لكل عملة.
- **المرافق:** مرافق وصيانة وحجز بمنع التعارض وإلغاء.
- **الشهادات الرقمية:** إصدار برمز تحقق، طباعة شهادة A4، سحب بسبب، وصفحة تحقق عامة بالاسم المختصر.
- **التحليلات المتقدمة:** نظرة عامة، المواد (متوسط ونجاح)، الحضور مقابل التحصيل (ارتباط)، اتجاه الشعب وتوقع استرشادي (Chart.js).
- اختبارات: 15 اختبارًا جديدًا (القبول، الإنذار، الإرشاد، الرواتب، المرافق، الشهادات، التحليلات، الصلاحيات والعزل). متصفح E2E: دورة كاملة لكل وحدة، عرض 360px بلا تمرير أفقي، و403 للمعلم على الوحدات الإدارية.
- **لم يُنفَّذ / قيود معروفة:** لا حساب غياب موظفين أو ضرائب أو تأمينات في الرواتب (D-56)؛ شهادات PDF عبر الطباعة من المتصفح؛ تبديل مدرسة ولي الأمر متعدد المدارس؛ منتدى الطلاب؛ مزود واتساب؛ نقل درجات الاختبارات آليًا؛ الاختبارات على MariaDB 10.11 فقط (لم تُجرَّب على MySQL 8).

- **لم يُجرَّب على مزود دفع حقيقي**: كل مزود له واجهة وتوقيع مختلفان؛ الإعداد عام (مسارات JSON وقوالب) وقد يحتاج بعض المزودين (خصوصًا المحافظ المحلية بلا واجهات مفتوحة، أو من يستخدمون SOAP/XML أو توقيعًا غير HMAC-SHA256 أو إعادة توجيه بنماذج HTML) إلى محوّل مخصص. اختبر في بيئة المزود التجريبية قبل الإطلاق وبمبالغ صغيرة.
- **غير مشمول:** الاسترداد (Refund) عبر المزود، عمولات المزود، الدفع بالدولار/الريال السعودي لرسوم بعملة أخرى (تُدفع بعملة الرسوم نفسها)، تحويل الأموال بين مدارس.
