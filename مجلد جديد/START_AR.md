# مدرستي — البدء السريع

## أولًا: تشغيل أول مرة

### الطريقة 1 — الأسهل للتجربة (قاعدة جاهزة ببيانات تجريبية)
1. ضع مجلد المشروع في `C:\wamp64\www\school-platform` (WAMP) أو أي مجلد استضافة، وتأكد أن الموقع يشير إلى مجلد `public`
   (أو افتح `http://localhost/school-platform/public/`).
2. من phpMyAdmin: أنشئ قاعدة `yemen_school_db` (ترميز `utf8mb4_unicode_ci`) ثم **Import** للملف `database/ready/madrasati-ready.sql`.
3. انسخ `database/ready/.env.ready` إلى جذر المشروع وسمّه `.env` (عدّل `DB_USER`/`DB_PASS` و`APP_BASE_PATH` إن لزم).
4. افتح الموقع. ادخل بأحد الحسابات:

| الدور | الدخول | كلمة المرور |
|---|---|---|
| مشغّل المنصة | `admin@example.com` | `Admin12345` |
| مدير المدرسة | `director@demo.test` | `Demo12345` |
| معلم | `khaled.demo@school.test` | `Demo12345` |
| محاسب | `acc.demo@school.test` | `Demo12345` |
| مرشدة | `counselor.demo@school.test` | `Demo12345` |
| طالب | اسم المستخدم `d0001` | `Demo12345` |
| ولي أمر | الهاتف `0773001001` ← تبويب «رمز SMS» (الرمز يظهر في `storage/logs/sms.log` لأن المزود تجريبي) | — |

> مفتاح التشفير في `.env.ready` معروف علنًا للتجربة فقط. للإنتاج ثبّت من الطريقة 2.

### الطريقة 2 — التثبيت النظيف (للإنتاج)
1. افتح الموقع ← يحوّلك تلقائيًا إلى معالج `/install`.
2. أدخل بيانات القاعدة (يمكنه إنشاء القاعدة إن لم تكن موجودة)، وحساب مشغّل المنصة.
3. (اختياري) علّم «تحميل مدرسة تجريبية» لبيانات جاهزة للتجربة.
4. يُنشئ المعالج `.env` ومفتاح تشفير خاصًا بك، ويقفل نفسه.

## ثانيًا: التحديث إلى إصدار جديد
1. خذ نسخة احتياطية من القاعدة ومن `.env` و`storage/`.
2. فك الحزمة الجديدة **فوق** المجلد الحالي (لا تحذف المجلد القديم) مع إبقاء `.env` و`storage/`.
3. افتح الموقع: تُنفَّذ الترقية (migrations) تلقائيًا عند أول زيارة. (أو: `php bin/migrate.php`).

إن حذفتَ `storage/installed.lock` أو نقلتَ المجلد وبقي `.env` والقاعدة: يستعيد النظام القفل تلقائيًا ولا يطلب التثبيت.
إن فقدتَ `.env`: افتح `/install` واختر القاعدة نفسها (تُستعاد دون المساس بالبيانات) والصق مفتاح التشفير القديم في «لدي تثبيت قديم».

## ثالثًا: مهام مجدولة (cron / Task Scheduler)
```
* * * * *   php /path/bin/cron-notifications.php   # طابور الرسائل
30 2 * * *  php /path/bin/cron-backups.php         # النسخ الاحتياطي التلقائي للمدارس
0 3 * * *   php /path/bin/backup.php               # نسخة كاملة للقاعدة (للمشغّل)
```
